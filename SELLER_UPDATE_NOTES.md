BookNest seller UX update

- Add Book is now a focused essential-only form. Photos and detailed descriptions are managed in Inventory.
- Inventory has the primary Add Book button.
- Saved Books list was removed from Add Book; Inventory is the single management list.
- Add to Shop has a condition checklist that automatically builds condition notes into the listing description.
- Seller password changes sync to the BookNest Supabase project so the changed password can be used on another device.
