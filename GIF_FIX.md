# GIF Fix

The supplied images were single-frame GIF/PNG artwork, so they were converted into genuinely animated looping GIFs with gentle bob/float motion. The Sorry artwork uses the same #F8F3E7 background as the site-closed card; the Thank You artwork is composited onto the same confirmation-panel paper color. Cache-busting query strings are added so Vercel browsers do not keep the old one-frame files.
