# ✅ STEP-BY-STEP: How to Add Books & Display in Shop

## STEP 1: Open Inventory Page
1. Click "Inventory & Sales" button at the top
2. You should see the inventory list with an "Add Book" form at the top

## STEP 2: Fill in Book Details

You'll see these fields:
- **Title** - Name of the book (e.g., "Harry Potter")
- **Author** - Author name (e.g., "J.K. Rowling")
- **Genre** - Select from dropdown (Fiction, Self-Help, etc.)
- **Price** - How much you want to sell it for (e.g., 250)
- **Stock** - How many copies you have (e.g., 5)
- **Type** - Paperback, Hardbound, etc.
- **Condition** - New, Pre Loved, Remaindered
- **Box** - What box/batch it came from (optional)

### EXAMPLE:
```
Title: Harry Potter and the Philosopher's Stone
Author: J.K. Rowling
Genre: Fantasy
Price: 250
Stock: 3
Type: Paperback
Condition: Pre Loved
Box: ThriftStore Feb2026
```

## STEP 3: Click "Add Book" Button
- Green button that says "+ Add Book"
- You'll see a popup saying "✓ Book added successfully!"
- The form clears automatically

## STEP 4: Add a Picture (OPTIONAL but RECOMMENDED)
1. Find your new book in the inventory table below
2. Look for the "📷 Photo" button on the right side
3. Click it
4. Select an image from your computer
5. Wait for it to upload and compress
6. Picture will show as a thumbnail

## STEP 5: Add Book to Shop (VERY IMPORTANT!)
1. Find your book in the inventory table
2. Look for a button that says "➕ Add Shop" 
3. Click it
4. Button will change to "🛒 In Shop"
5. **Now buyers can see your book!**

---

## MAKING BOOKS VISIBLE vs INVISIBLE

### To Show a Book (Add to Shop):
- Table column "Actions" → Click "➕ Add Shop"
- Button changes to "🛒 In Shop" (purple/teal color)
- Buyers can now buy it
- Stock appears in shop

### To Hide a Book (Remove from Shop):
- Find the book with "🛒 In Shop" button
- Click "🛒 In Shop" button
- Button changes back to "➕ Add Shop"
- Book disappears from shop BUT stays in your inventory
- You can add it back anytime

### To Delete a Book (Remove from Inventory):
- Click "Delete" button
- Book is GONE (can undo immediately with notification)

## COMMON ISSUES

### ❌ PROBLEM: Can't see "Add Shop" button

**SOLUTION:** 
1. Scroll to the right in the inventory table
2. The "Actions" column is on the far right
3. Look for the blue/purple buttons

### ❌ PROBLEM: Added book but doesn't appear in shop

**SOLUTION:**
1. Did you click "➕ Add Shop"? (Step 5 above)
2. Check "View Shop" tab to see if it's there
3. If not visible, book might be hidden - click "🛒 In Shop" button

### ❌ PROBLEM: Book appears in inventory but not in shop

**SOLUTION:** 
- Go to View Shop
- Search for the book name
- If not there: **You forgot to click "Add Shop"!**
- Go back to Inventory
- Find the book
- Click "➕ Add Shop" button

### ❌ PROBLEM: Stock shows as 0

**SOLUTION:**
- Go to Inventory
- Find the book row
- Click on the Stock number
- Change it to a higher number (e.g., 1, 5, 10)
- Press Enter or click elsewhere to save
- Book needs Stock > 0 to show in shop

### ❌ PROBLEM: Picture didn't upload

**SOLUTION:**
1. Try a smaller image file (less than 2MB)
2. Make sure it's a JPG or PNG
3. Try again with the "📷 Photo" button
4. Check browser console (F12) for errors

## 📱 WHAT BUYERS SEE

When you click "Add Shop", buyers see:
- ✅ Book cover picture
- ✅ Title
- ✅ Author
- ✅ Genre
- ✅ Price
- ✅ Stock status
- ✅ "Add to cart" button

Buyers DO NOT see:
- ❌ Box information
- ❌ Condition notes
- ❌ Your personal notes
