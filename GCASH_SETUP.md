# 💳 STEP-BY-STEP: GCash Setup (QR Code Upload)

## WHAT YOU NEED

1. Your **GCash phone number** (e.g., 09171234567)
2. Your **GCash QR code** (as an image file)

### How to Get Your GCash QR Code:
1. Open GCash app on your phone
2. Look for "Receive Money" or "Collect" button
3. Tap on "QR Code" option
4. Take a screenshot of your QR code
5. Transfer that image to your computer

---

## STEP 1: Go to Admin Home
1. Click "Home" in the top navigation
2. You should see the "💳 GCash Payment Setup" section

---

## STEP 2: Enter GCash Phone Number
1. Find the field labeled "GCash Phone Number"
2. Type your GCash number (e.g., 09171234567)
3. Example format: 09XXXXXXXXX

---

## STEP 3: Upload QR Code Image
1. Find the button that says "📷 Upload QR Code"
2. Click the button
3. Select the GCash QR code image from your computer
4. Wait for it to process (takes a few seconds)
5. You should see a preview of the QR code below the button

### If preview appears:
- ✅ Upload was successful!
- The image preview should show your QR code
- A "Remove" button will appear next to upload button

### If preview doesn't appear:
- ❌ Try again with a different image
- Make sure it's a JPG or PNG file
- Try a smaller image size
- Refresh the page and try again

---

## STEP 4: Save Your Settings
1. Click the green button "💾 Save GCash Details"
2. Wait for confirmation popup
3. It should say "✓ GCash details saved successfully!"
4. Click OK

---

## VERIFYING IT WORKS

### Check on Inventory Page:
1. Go to "Inventory & Sales"
2. Look at the stats - your data should appear

### Check on Payment Info:
1. Go to "View Shop"
2. Click on "Payment info" in the sidebar
3. You should see:
   - Your QR code preview
   - Your GCash phone number
   - Payment instructions

### Check on Checkout:
1. Go to "View Shop"
2. Try adding a book to cart
3. Click "Proceed to checkout"
4. Choose GCash as payment method
5. Fill in details and click "Place order"
6. **You should see your QR code on the confirmation screen!**

---

## COMMON ISSUES & FIXES

### ❌ ISSUE: "Upload QR Code" button doesn't work

**Fix 1:** Try refreshing the page
- Press Ctrl+R (or Cmd+R on Mac)
- Wait for page to fully load
- Try uploading again

**Fix 2:** Try a different image
- Make sure QR code image is clear
- Not blurry or cut off
- Try a JPG instead of PNG

**Fix 3:** Check browser storage
- GCash setup stores data locally
- If this doesn't work, browser storage might be full
- Try clearing browser cache
- Go to Settings → Clear browsing data

### ❌ ISSUE: Image uploaded but no preview shows

**What probably happened:**
- Image processing failed
- Try with a smaller image file
- Try different image format

**How to fix:**
1. Click "Upload QR Code" again
2. Select a different image file (smaller size)
3. Wait for preview to appear

### ❌ ISSUE: "Save" button doesn't work

**Fix 1:** Make sure you entered SOMETHING
- Need either: GCash number OR QR code image
- Better to have BOTH

**Fix 2:** Check if number format is correct
- Should be 11 digits starting with 09
- Example: 09171234567

**Fix 3:** Try entering number again
- Click in the GCash Phone Number field
- Clear it completely (Ctrl+A then Delete)
- Type your number again
- Try Save

### ❌ ISSUE: QR code doesn't appear to buyers

**Checklist:**
- [ ] Did you click "Save GCash Details" button?
- [ ] Does the confirmation say "✓ saved successfully"?
- [ ] Did you refresh the shop page after saving?
- [ ] Does "View Shop" → "Payment info" show your QR?

**If all yes:** QR should appear in checkout!

## STILL NOT WORKING?

1. **Open Browser Console (F12):**
   - Look for any red error messages
   - Screenshot the error
   - Note what you were doing

2. **Try Different Browser:**
   - Chrome, Firefox, Safari, Edge
   - See if it works in a different browser

3. **Restart Browser:**
   - Close browser completely
   - Open again
   - Go back to Admin → GCash Setup
   - Try again

4. **Hard Refresh:**
   - Ctrl+Shift+R (Windows)
   - Cmd+Shift+R (Mac)
   - Forces browser to reload everything
   - Try setup again
