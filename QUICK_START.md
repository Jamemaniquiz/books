# BookNest Quick Start - Seller Checklist

## ✅ First Time Setup

### 1. Set Up GCash Payment
- [ ] Go to Admin Home
- [ ] Find "GCash Payment Setup" section
- [ ] Enter your GCash phone number
- [ ] Upload your GCash QR code image
- [ ] Click "Save GCash Details"

### 2. Add Your First Book
- [ ] Go to "Inventory & Sales"
- [ ] Click "Add Book"
- [ ] Fill in: Title, Author, Genre, Price, Stock, Type, Condition
- [ ] Click "📷 Photo" to add a picture
- [ ] Select image from your computer
- [ ] Click "➕ Add Shop" to make it visible
- [ ] Button should show "🛒 In Shop"

### 3. Test the Shop
- [ ] Click "🛒 View Shop" in top navigation
- [ ] Verify your book appears
- [ ] See the price, photo, and details
- [ ] Try adding to cart and checkout process
- [ ] Verify your GCash QR code and number show up

---

## 📚 Daily Operations

### Adding More Books
```
Inventory → Add Book → Fill Details → Upload Photo → Click "Add Shop"
```

### Recording a Sale (In-Person)
```
Inventory → Click "Sold" → Enter Quantity → Receipt Generates
```

### Checking Sales History
```
Admin Home → Look at "Recent Activity" section
```

### Backing Up Everything
```
Admin Home → "Download Full Transfer Backup" → Save File Somewhere Safe
```

## 💳 When Buyer Places Order

### You See:
- Order appears in "🛒 Shop Orders" page
- Their name, address, contact info
- List of books ordered
- Total amount due
- Payment method (GCash or Bank Transfer)

### They See:
- Order ID and confirmation
- Your GCash QR code (if GCash was selected)
- Total amount to pay
- Your GCash number
- "Payment info" tab with full payment details

### Your Next Step:
- Mark as "Paid" once you receive payment
- Process shipment (2 weeks delivery time)
- Mark as "Shipped" to notify buyer

## 🖼️ Picture Storage (Important!)

**Your Pictures Are Safe Because:**
- ✓ Saved in browser storage (NOT temporary)
- ✓ Won't delete when you refresh page
- ✓ Won't delete when you close browser
- ✓ Stay until YOU manually delete them

**BUT:**
- ⚠️ Each device/browser has separate storage
- ⚠️ If you clear browser cache = pictures gone
- ⚠️ NOT saved to internet/cloud automatically

**Protect Your Pictures:**
- Download backup every week
- Use same browser/computer when adding books
- Never clear browser cache

**If You Lose Pictures:**
- Restore from backup file
- Re-upload new photos

## 🛒 Shop Management

### To Make a Book Visible
- Click "➕ Add Shop" button next to book
- Button changes to "🛒 In Shop"

### To Hide a Book (Keep It, Don't Sell)
- Click "🛒 In Shop" button
- Button changes to "➕ Add Shop"
- Book stays in inventory but buyers don't see it

### To Permanently Delete a Book
- Click "Delete" button
- Undo with toast notification if needed

### Stock Management
- Edit "Stock" number directly to add/remove copies
- System tracks how many you have
- Buyers can only buy available stock

## 🚀 Pro Tips

1. **Use Box Names for Organization**
   - Tag all books from same batch with same box name
   - Example: "Amazon Haul 1", "Thrift Store Feb 2026"
   - Helps track profitability per source

2. **Keep Prices Rounded**
   - ₱100, ₱150, ₱200
   - Easier for customers, less confusion

3. **Use Clear Photos**
   - Good lighting, straight angle
   - Shows condition clearly
   - Increases sales

4. **Update Stock Regularly**
   - Edit stock number as you sell
   - Keeps data accurate
   - Buyers see real availability

5. **Back Up Weekly**
   - Literally takes 30 seconds
   - Worth the peace of mind
   - Can transfer to new device anytime

---

## ❌ Don't Do This

- ❌ Don't clear browser cache (loses pictures)
- ❌ Don't use multiple browsers (data doesn't sync)
- ❌ Don't forget to add books to shop (buyers won't see them)
- ❌ Don't ignore stock updates (confuses customers)
- ❌ Don't skip backups (no way to recover if device breaks)
