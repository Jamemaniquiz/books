# BookNest Buyer Site Lock

The Seller Center now has **Buyer Site Availability**. Toggle **Lock the buyer side** to temporarily take the public buyer experience offline. The lock is stored in Supabase under `.site_status`, so it applies to the Vercel site and other devices.

`site-closed.gif` is shown with the temporary-down explanation. `thank-you.gif` is shown on the buyer order confirmation screen after a successful checkout.

The provided PNG images were converted to one-frame GIF files so the requested GIF assets can be referenced by the website.
